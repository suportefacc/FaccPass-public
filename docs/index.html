Sobre o FaccPass

O FaccPass é um gerenciador de senhas para organizações que precisam manter o controle de credenciais por setor. Cada setor possui o seu próprio cofre de senhas e o acesso é governado por papéis:

  • viewer — visualiza senhas do seu setor
  • admin — cria e edita senhas + gerencia usuários do setor
  • superadmin — acesso ao setor pessoal + setor de TI
  • mestre — administração total (dono do setor de TI)

Todas as senhas são armazenadas criptografadas com AES-256, com IV único por senha, e toda ação é registrada em um log de auditoria.

Extensão para Chrome

A extensão FaccPass se conecta à API do seu servidor e permite gerenciar credenciais diretamente pelo navegador:

  • Copiar credenciais de sites em um clique
  • Preenchimento automático de formulários de login
  • Gerador de senhas seguras
  • Gestão de usuários, setores e permissões

Privacidade e Segurança

A extensão utiliza as permissões solicitadas de forma mínima e justificada:

  • storage — guarda localmente o token de sessão e preferências de preenchimento
  • activeTab / tabs / scripting — acessam a aba ativa apenas quando o usuário usa a extensão para preencher formulários
  • notifications — informam o resultado do preenchimento automático
  • host permissions — conexão exclusiva com a API do FaccPass do seu servidor

A extensão não executa código remoto. Ela apenas consulta dados (JSON) da API do FaccPass. Nenhum dado é vendido ou compartilhado com terceiros.
