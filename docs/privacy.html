Política de Privacidade — FaccPass

Última atualização: setembro de 2026

Esta política descreve como a extensão do Chrome FaccPass trata os dados. O FaccPass é um gerenciador de senhas voltado ao uso em ambientes corporativos, hospedado e administrado pela própria organização que o utiliza.

1. Dados coletados

A extensão coleta e processa os seguintes dados, fornecidos diretamente pelo usuário ou pela organização:

  • Credenciais de acesso (usuário e senha) armazenadas nos cofres setoriais;
  • Dados de perfil do usuário necessários ao controle de acesso (nome, papel, setor);
  • Informações de sessão (token de autenticação) necessárias para comunicação com a API.

2. Finalidade e uso

Os dados são usados exclusivamente para:

  • Armazenar, gerenciar e recuperar as credenciais do cofre do setor; e
  • Executar o preenchimento automático de formulários de login em páginas da organização.

3. Armazenamento e segurança

As senhas são criptografadas com AES-256 a partir do servidor, nunca transmitidas em claro na resposta da API de listagem, e a autenticação se dá via JWT com expiração. O token de sessão é mantido localmente no navegador (chrome.storage.local) e nunca é enviado a terceiros.

4. Permissões e justificativa

  • storage: guarda localmente o token de sessão e as preferências de preenchimento (autoFill, autoFillDelay).
  • activeTab: permite acessar a aba ativa somente quando o usuário clica na extensão para preencher um formulário de login.
  • scripting: injeta o preenchimento no formulário detectado da aba ativa, sob solicitação do usuário.
  • tabs: identifica a aba ativa para exibir as senhas correspondentes ao domínio visitado.
  • notifications: notifica o usuário sobre a conclusão do preenchimento automático.
  • Host permissions: conexão exclusiva com a API do FaccPass (endereço corporativo configurado). Nenhum outro host é acessado.

5. Compartilhamento de dados

A extensão não vende, não aluga e não compartilha dados pessoais com terceiros. Os dados trafegam apenas entre o navegador do usuário e o servidor do FaccPass administrado pela organização.

6. Código remoto

A extensão não executa código remoto. Ela consulta exclusivamente dados em formato JSON da API do FaccPass. Todo o código executável está empacotado na própria extensão.

7. Retenção e exclusão

Os dados permanecem nos cofres enquanto a organização assim definir. A exclusão de senhas e usuários é realizada pelos administradores através da própria aplicação.
